# Wear Active Dawn Theme — Agent Instructions

## Project
This is a Shopify Dawn-based theme for Wear Active.

## Rules
- Work only on the current feature branch.
- Never push directly to main.
- Keep custom code namespaced with `wa-`.
- Prefer new snippets/assets over modifying Dawn core files.
- Do not add third-party apps or external libraries unless approved.
- Keep Dawn performance-first: minimal JavaScript, lazy loading, no unnecessary animations.
- Use Shopify native metafields/metaobjects where possible.
- Run `shopify theme check` before finishing.
- Explain all changed files clearly.
- Do not change checkout, cart logic, payment, or existing Shopify settings unless specifically asked.
