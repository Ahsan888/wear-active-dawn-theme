# Wear Active Dawn Theme Rules

- Never push directly to main.
- Always create feature branches from dev.
- Run `shopify theme check` before committing.
- Do not use paid apps unless approved.
- Prefer native Shopify metafields/metaobjects.
- Keep Dawn lightweight and performance-first.
- Avoid unnecessary JavaScript.
- New sections/snippets should be reusable.
- Do not edit live theme directly from Shopify admin.
- Main branch is production-ready only.
